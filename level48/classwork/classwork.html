CSS Box Model

Box Model არის მოდელი, რომელიც აღწერს ელემენტის ზომას. იგი შედგება 4 შრისგან:

  • Content - ელემენტის შიგთავსი
  • Padding - შიდა დაშორება
  • Border - ჩარჩო
  • Margin - გარე დაშორება

CSS Reset

CSS Reset გამოიყენება default სტილების მოსაშორებლად.

box-sizing: border-box
