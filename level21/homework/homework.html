C++ ენის შექმნა

C++ პროგრამირების ენა შეიქმნა 1979 წელს ბიარენ სტროსტრუპის მიერ. თავდაპირველად იგი წარმოადგენდა C ენის გაუმჯობესებულ ვერსიას, რომელსაც დაემატა ობიექტზე ორიენტირებული პროგრამირების შესაძლებლობები.

C++ ენის განვითარება და გამოყენება

დროთა განმავლობაში C++ გახდა ერთ-ერთი ყველაზე პოპულარული პროგრამირების ენა. იგი ფართოდ გამოიყენება თამაშების შექმნაში, ოპერაციულ სისტემებში, embedded სისტემებში და მაღალი წარმადობის პროგრამებში.

საინტერესო ფაქტი

C++ დღემდე აქტიურად ვითარდება და რეგულარულად გამოდის ახალი სტანდარტები, როგორიცაა C++11, C++17 და C++20.
