პროგრამირების ენის განვითარება და ევოლუცია

C++-ის შექმნა და ადრეული წლები

C++ პროგრამირების ენა შეიქმნა 1979 წელს Bell Labs-ში ბიარნე სტროუსტრუპის მიერ. თავდაპირველად ენას ერქვა "C with Classes" (კლასებით C), რადგან იგი C ენის გაფართოება იყო.

1983 წელს ენას სახელი შეეცვალა და დაარქვეს C++. სახელში "++" არის C ენის ინკრემენტის ოპერატორი, რომელიც მიუთითებს, რომ ეს ენა არის C-ის გაუმჯობესებული ვერსია. 1985 წელს გამოვიდა პირველი კომერციული გამოშვება.

C++-ის სტანდარტიზაცია და თანამედროვე განვითარება

1998 წელს C++ გახდა სტანდარტიზებული ენა ISO/IEC 14882:1998 სტანდარტის მიხედვით. ეს იყო პირველი ოფიციალური სტანდარტი, რომელმაც დაზუსტა ენის სინტაქსი და ბიბლიოთეკები.

მომდევნო წლებში C++ განვითარდა და გამოვიდა მისი ახალი სტანდარტები: C++11 (2011), C++14 (2014), C++17 (2017) და C++20 (2020). თითოეულმა ახალმა სტანდარტმა ენას დაუმატა თანამედროვე ფუნქციები.

მნიშვნელოვანი მოვლენები

1979: ბიარნე სტროუსტრუპი იწყებს "C with Classes" შემუშავებას

1983: ენას ეწოდება C++

1985: პირველი კომერციული რელიზი

1998: პირველი ISO სტანდარტი (C++98)

2011: C++11 - მნიშვნელოვანი განახლება

2020: C++20 - თანამედროვე ფუნქციები

C++-ის გამოყენება

C++ ფართოდ გამოიყენება ოპერაციულ სისტემებში, თამაშების დეველოპმენტში, მაღალი პროდუქტიულობის აპლიკაციებში, ჩაშენებულ სისტემებში და ვებ ბრაუზერებში.
